# Scattered worksheet cover artwork (v1.437.0, Big M cover v1.438.0)

Since v1.438.0 the shared cover (`WorksheetCover.render`, used by every cover the main app prints) is the **Big M** design. It draws 31 icons from the same atlases at placements taken from the approved A4 design (`M_ICONS` in `worksheet-cover.js`, as percentages of the sheet), the same bubble/polygon textures minus the few that would sit under the M, and the faceted M as a printable SVG in the top-right band. Its defaults are faint: icons at 0.38, textures at 0.6, the M at full strength. `decoration()` without `design: 'big-m'` keeps the arrangements below for Custom Paper and the two worksheet creators.

Generated with the built-in image generation tool on 22 October 2026. The unmodified 1254 × 1254 RGBA PNG files `science-icons-v2.png` and `math-icons-v2.png` have sixteen motifs each in a 4 × 4 arrangement. Every cover uses a deterministic scatter of 34 small icons by default, all sixteen motifs, plus separate printable SVG bubble, polygon and dot textures. Frame and airy options retain smaller icons. Custom exam covers place most icons in the lower whitespace.

The originals with six motifs are retained as `science-icons.png` and `math-icons.png`; current covers use the v2 files. The generated sheets have uneven gutters, so display crops use inspected transparent seams to keep whole motifs and exclude neighbouring fragments. The source PNGs are unchanged. Raster cells render as image elements; textures use SVG fills so both export with browser background graphics disabled. Text, labels, placement style, size, icon visibility and texture intensity remain editable and saved.

Science grid: atom, test tubes, flask, microscope / DNA, seedling, magnet, thermometer / bulb, planet, gear, water drop / battery, beaker, magnifying glass, leaf.

Math grid: π, √, +, − / ×, ÷, =, % / ∞, Σ, ≠, ≤ / ≥, θ, ∠, ½.

## Exact generation prompts

### science-icons-v2.png

Use case: scientific-educational. Production transparent pixel icon sprite atlas for printed Polymath worksheet covers. Create ONE SQUARE 1536x1536 transparent PNG: exactly SIXTEEN isolated icons in a perfectly uniform FOUR COLUMN by FOUR ROW grid (384x384 square cells). Every icon centered in its equal cell, limited to about 240x240 pixels with at least 60px fully empty margin on all sides, no overlap between cells. Clean readable 16-bit pixel art, chunky square pixels, simple strong silhouettes, flat LIGHT PASTEL mint, pale aqua, blush pink, pale lilac with dusty teal/pink outlines derived from a teal and magenta brand. These icons will be displayed SMALL around 25–40px, so favor recognisable simplified shapes without intricate detail. Transparent alpha outside artwork. No background, no checkerboard, no border around cells, no glow, no shadows, no labels, no watermark, no overall logo. Consistent line weight and size across all 16 cells. SCIENCE ONLY. Row1 left to right: atom with orbital loops, pair of laboratory test tubes, conical flask, microscope. Row2: DNA double helix, two-leaf seedling, horseshoe magnet, thermometer. Row3: light bulb, ringed planet Saturn, gear wheel, water droplet. Row4: battery, laboratory beaker, magnifying glass, single leaf. Each cell has ONLY the one named science icon. No mathematical symbols, no letters, no words. All 16 icons are distinct, precisely in the given grid order.
