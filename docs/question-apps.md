# Interactive question apps

In the question editor, choose **Add Interactive App** (also available between blocks). Paste a complete HTML app or import an `.html` file, then choose **Preview pasted app**. Inline HTML, CSS and JavaScript work; external resources and network requests are blocked. The supplied grasshopper example works with its built-in text logo fallback.

Alternatively, enter directions and choose **Generate app for this question**. The current question text, answers and up to three diagrams are included. **Maximum output tokens** defaults to 4,096 and accepts 1,024–32,000, matching the existing centre AI service. The same ceiling applies to refinement. This is a per-request output/reasoning limit, not a total spending cap; input tokens are additional. There is one selected-provider request, without automatic fallback or retries. Incomplete responses keep the previous app. ChatGPT uses the centre's server configuration; Gemini supports the effort selector. See the [OpenAI API reference](https://developers.openai.com/api/reference/resources/chat) for output token accounting.

Review the app before saving. Saving a bank/vetting question publishes its app and persists the link. **Publish app & QR code** can publish a draft explicitly. Custom paper, worksheet, syllabus, bank, learning-objective and Study Buddy exports publish pending apps before rendering. A publication failure stops the export with an error; read-only previews show an unpublished notice. Students see the embedded activity after their answer is marked. Paper users can scan the QR independently; printed completion cannot be enforced.

Published snapshots contain only `{version,title,html,height}`. They use `cer-images/question-app-<sha256>.json` and a tokenized download through `question-app.html`. Changed content gets a new immutable URL so previous worksheets continue to open their original app. Publishing again does not revoke old printed links. The viewer needs no account, reads no question bank, verifies the content digest, limits download size, and renders in an opaque-origin `allow-scripts` iframe with an injected restrictive CSP. Only put student-facing material in an app.

QR images are generated locally as SVG with the bundled MIT-licensed `qrcode-generator` library, not by a third-party QR service. Existing Firebase Storage rules were inspected and support this path; no rules or backend deployment change is needed. No paid model request is made by the test suites.

Validation lives in `tools/question-apps*-tests.mjs`, `tools/widget-generation-tests.mjs`, `tools/widget-editor-tests.mjs`, `tools/widget-save-tests.mjs`, `tools/widget-print-tests.mjs` and `tools/widget-editor-browser-tests.mjs`. Optional `WIDGET_SAMPLE_HTML` exercises a local sample without committing it.
